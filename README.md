# Biznes-Maslahatchi AI — Умный ИИ-финансовый советник и генератор бизнес-планов для МСБ

**National AI Hackathon: Tashkent • Команда «Парабола 2.0» • Кейс #20 (Торгово-промышленная палата РУз)**

Интеллектуальная веб-платформа класса Neuro-Symbolic AI для предпринимателей малого и среднего бизнеса Узбекистана: помогает подобрать нишу и район, настроить параметры проекта в диалоге с ИИ, сравнить 3 режима налогообложения НК РУз 2026, выбрать оптимальный кредит среди **10 банков Узбекистана** с учётом льготного периода и выгрузить готовые документы (банковское ТЭО, личный план предпринимателя с законами РУз и инвест-презентацию).

---

## Ключевые возможности

1. **Автономный ИИ-консультант (`RU` | `UZ`) с изменением параметров в реальном времени:**
   - Понимает запросы на русском и узбекском (латиница) языках (`extractAgentActionsFromPrompt` в `src/utils/aiEngine.ts`), автоматически обновляет район, площадь, штат, бюджет, кредит, льготный период, налоговый режим и банк.
   - Гибридный контур: работает даже в офлайн/резервном режиме за ~180 мс без галлюцинаций и подключается к **Google Gemini API** через серверный прокси `/api/ai-consultant`.
   - Подготовлена кнопка голосового ввода STT (в дорожной карте для RU/UZ).

2. **Детерминированное финансовое ядро (`src/utils/calculations.ts`):**
   - **CAPEX / OPEX / Cashflow:** отраслевая разбивка стартовых инвестиций, аренда по ставкам **12 районов Ташкента**, ФОТ, себестоимость (COGS %), точка безубыточности (точный бинарный поиск `findExactBreakEvenRevenue`), срок окупаемости (расчёт на горизонте до **99 месяцев**) и годовой ROI %.
   - **Гибкий горизонт графика окупаемости:** режим **«🎯 До выхода в плюс»**, `12`, `24` или `36 мес.`, а также **KPI** (DSCR, запас прочности, дневной поток клиентов) и **Milestones** запуска.

3. **Полное сравнение 10 банков Узбекистана с льготным периодом:**
   - **Агробанк**, **Банк развития бизнеса (BRB)**, **Ипак Йули Банк**, **Узпромстройбанк (SQB)**, **Aloqabank**, **Узнацбанк (NBU)**, **Капиталбанк**, **Hamkorbank**, **Asia Alliance Bank**, **Трастбанк**.
   - Расчёт аннуитетного и дифференцированного графика с **льготным периодом (3–24 мес., оплата только %)**, расчётом **DSCR**, шансом одобрения и рекомендацией Топ-3 банков без прямого оформления заявки на сайте.

4. **Налоговый калькулятор по Налоговому кодексу РУз (2026):**
   - Одновременное сравнение 3 режимов: **Самозанятый** (`1 БРВ / год = 375 000 сум`, до 100 млн/год без наёмных сотрудников), **ЯТТ / Налог с оборота 4%** (до 5 сотр. и 1 млрд сум/год + 12% соцналог) и **МЧЖ / Общеустановленный** (НДС 12% с зачётом входного НДС + Налог на прибыль 15% + соцналог 12%).

5. **12 районов Ташкента и конкурентная разведка:**
   - Индексы трафика, покупательской способности и стоимости аренды за `м²` по районам Ташкента (`src/data/tashkentDistricts.ts`), анализ 3 локальных конкурентов с УТП.

6. **3 формата PDF-документов + Excel/CSV экспорт (`src/components/BankPdfModal.tsx`):**
   - **ТЭО для банка:** официальный финансовый расчёт, таблицы CAPEX/OPEX, DSCR и график окупаемости.
   - **План для бизнеса (Путь + Законы РУз):** пошаговая дорожная карта предпринимателя с учётом законодательства РУз (`new.birdarcha.uz`, `e-imzo.uz`, `ijara.soliq.uz`, `my.soliq.uz`, `my.mehnat.uz`, `license.gov.uz`, `didox.uz`, ПКМ №943) и налоговый календарь.
   - **Презентация для инвестора:** 6 слайдов для питчинга.

7. **Тарифная модель Freemium:**
   - **Free** (`0 сум`, до 15 попыток ИИ/PDF) и **Pro** (**$15 / мес** / `192 750 сум`, безлимит).

## Стек технологий и архитектура

- **Frontend:** React `18.3.1`, TypeScript `~5.6.2`, Tailwind CSS `3.4.15`, Recharts `2.13.3`, Lucide React `0.460.0`.
- **Сборка и API-сервер:** Vite `5.4.11` + кастомный Node.js-плагин `biznesBackendPlugin()` в `vite.config.ts`:
  - `GET /api/health` — статус сервиса, поддерживаемых районов (12) и банков (10).
  - `GET /api/bank-rates` и `POST /api/bank-rates/refresh` — срез ставок 10 банков и ставки ЦБ РУз.
  - `POST /api/ai-consultant` — безопасный прокси-вызов к Google Gemini API с использованием серверного ключа окружения (`GEMINI_API_KEY` / `VITE_GEMINI_API_KEY`).

## Быстрый старт (локальный запуск)

### Требования
- **Node.js** `18+` и **npm**

### Установка и запуск

```bash
npm install
npm run dev
```

После запуска откройте [http://localhost:5173](http://localhost:5173).

### Сборка для продакшена

```bash
npm run build
npm run preview
```

### Подключение собственного Gemini API ключа (опционально)

Скопируйте `.env.example` в `.env` и укажите ваш ключ Google AI Studio:

```env
GEMINI_API_KEY=ваш_ключ_gemini
```

Без ключа приложение полностью функционально за счёт встроенного детерминированного движка NLU и финансовой математики.
